# Start Habits, Rise Up, Glow! (SHRUG!)

## 1. Project Title and Brief Summary
**Start Habits, Rise Up, Glow! (SHRUG!)**

For our project, we created a student-focused web application that functions as a task tracker and affirmation hub. The **SHRUG!** app allows users to input tasks and deliverables to build an organized list that supports time management and task completion, while also receiving mood-based affirmation messages to keep them motivated.

---
## 2. How to Run the Program (Instructions)

**a)** Access the website at:  
https://rhyanharris4.github.io/SHRUG-Website/login.html

**b)** Select **“Sign Up”** and enter a username, email, and password, then click **“Create Account.”**  — OR — log in using the email and password of an existing account.

**c)** Navigate through the site using the sidebar and on-screen options:

i) To add a task, select the **“Add Task”** button  
ii) On **“My Tasks”** / **“All Tasks”**, press the **⋮** option to mark a task completed, edit it, or delete it  
iii) Go to the **Affirmations Hub** to view more mood-based affirmations 
iv) Visit the **Homepage** to see the preview card of upcoming tasks and deliverables  
v) Use **“Log Out”** in the sidebar when finished  
vi) Log back in anytime to view previously saved tasks


## 3. Dependencies or Libraries Used

### a) Dependencies Used
These are the technologies the project relies on to function:

- **Firebase Authentication (firebase-auth.js)** - handles user account creation, login/logout, and authentication state tracking.

- **Firebase Firestore (firebase-firestore.js)** - cloud-based NoSQL (Not Only SQL) database used to store user profiles and task documents.

- **Firebase App (firebase-app.js)** - initializes the Firebase project and connects the frontend to Firebase services.

- **ECMAScript Modules (ES Modules)** - used to load Firebase as native JavaScript modules directly from Google’s CDN.

- **Browser Environment (Web APIs)** - DOM manipulation (`getElementById()`, `querySelector()`, etc.), event handling (`addEventListener()`), and fetch/promises (`fetch()`) were all required for the website to run.

### b) Libraries Used

- **Firebase JavaScript SDK** - provides the prebuilt modules for authentication, Firestore, and app initialization.
